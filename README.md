# @deepseek-ai/dsh-client-ui-design-center

Design center conversation tab plugin for [deepseek-harness](https://github.com/deepseek-ai/deepseek-harness). Renders architecture / modules / flows / plan boards as a native conversation tab, with edit and re-render support.

## Install

``ash
dsh plugin --profile web add git+https://github.com/ice-deep-dream/dsh-plugin-design-center.git
``

Then restart dsh (or the web profile) and open a session; the design-center tab will appear in the conversation panel.

## What it does

- Reads four board files generated by the dev-plan-assistant skill: architecture / modules / flows (SVG) and plan (JSON)
- Renders them as four subtabs inside a dedicated conversation tab
- Supports editing the plan card (text, version, updatedAt) and re-rendering animated SVG diagrams via the host-side Python renderer
