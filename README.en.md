> A design-center conversation tab plugin for [deepseek-harness](https://github.com/deepseek-ai/deepseek-harness): render architecture / modules / flows / plan boards natively inside the conversation panel, with inline editing and re-rendering.

<p align="center">
  <img alt="feature preview" width="760" src="./assets/feature.svg">
</p>

## Features

| Capability | Description |
| --- | --- |
| Four-in-one board | Organizes **Architecture**, **Modules**, **Flows**, and **Plan** as four subtabs within one dedicated conversation tab |
| Native conversation UI | Injected as a dsh client plugin — no popups, no page jumps, seamlessly blends into the chat experience |
| Clean monochrome | Renders `clean` (GitHub Wire) black/white/gray diagrams; deep-ink vs mid-gray strokes and solid vs dashed lines convey hierarchy & async |
| Animated flows | Flow diagrams play step-by-step; connectors use filled arrowheads with automatic line trimming to avoid overlap |
| Inline editing | Edit plan cards directly inside the panel (title, version, updatedAt, body) |
| Re-render | Re-draw architecture and flow diagrams with one click via the host-side Python renderer |
| Skill integration | Consumes the four design artifacts produced by the `dev-plan-assistant` skill out of the box |

## How it works

The plugin reads four design files generated by the `dev-plan-assistant` skill:

| File | Format | Rendered as |
| --- | --- | --- |
| Architecture | SVG | Architecture subtab |
| Modules | SVG | Modules subtab |
| Flows | SVG (animated) | Flows subtab |
| Plan | JSON | Editable plan card |

Once installed, open any conversation and the "Design Center" tab appears in the conversation panel.

## Prerequisites

This plugin does **not** bundle the board-generation capability. It is the UI companion to the [`dev-plan-assistant`](https://github.com/ice-deep-dream/skills-dev-plan-assistant) skill and depends on it at runtime:

- The board content (architecture / modules / flows SVGs and `plan.json`) is generated by the skill into `docs/design/diagrams/`; the plugin only reads and renders those files.
- When you click "↻ Re-render", the plugin invokes `~/.agents/skills/dev-plan-assistant/diagrams/archscribe/scripts/render_animated_diagram.py` on the host, so **the skill must be installed on the host alongside a Python 3 runtime**.

Install the skill first:

```bash
# Clone the dev-plan-assistant skill into the dsh skills directory
git clone https://github.com/ice-deep-dream/skills-dev-plan-assistant.git "$HOME/.agents/skills/dev-plan-assistant"

# Re-rendering requires Python 3 (preinstalled on most macOS / Linux; Windows users can get it from python.org)
python --version
```

> Viewing already-generated SVG boards works without the skill or Python; (re)generating diagrams, however, requires both.

## Installation

Once the prerequisites are met, install via the dsh plugin manager with the web profile:

```bash
dsh plugin --profile web add git+https://github.com/ice-deep-dream/dsh-plugin-design-center.git
```

Then restart dsh (or reload the web profile) and open a session — the design-center tab will be available. For first use, let `dev-plan-assistant` initialize the project in a session so it generates the board files under `docs/design/diagrams/`.

## Development

This is the standalone publish repository; build artifacts live in `lib/`. After building from the harness source, sync the compiled output into the `lib/` directory here.

Directory structure:

```text
dsh-plugin-design-center/
├── assets/                  # README icons and feature illustration
├── lib/                     # Compiled output (published with the package)
│   ├── index.js             # Plugin entry
│   ├── client.js            # Client injection (the design-center tab)
│   ├── invariant.js         # Runtime constants (PACKAGE_NAME, etc.)
│   └── types/               # TypeScript declarations
├── package.json
├── .gitignore
├── README.md
└── README.en.md
```

The host injects these client modules at runtime: `@deepseek-ai/dsh-client-locale`, `@deepseek-ai/dsh-client-runtime`, `@deepseek-ai/dsh-client-ui-conversation`. React >= 18 is required.
